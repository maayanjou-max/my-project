# 🏥 סוכן מידע תרופות - Drug Information Agent

## סיכום השינויים

נוצר סוכן חכם לחיפוש מידע על תרופות ממקורות רפואיים מהימנים בלבד.

## תכונות עיקריות

✅ **חיפוש מהימן**: רק מקורות רפואיים מוסמכים (MedlinePlus, MicroMedex, UpToDate)
✅ **תמיכה דו-לשונית**: עברית ואנגלית
✅ **מיפוי שמות**: שמות גנריים ומסחריים
✅ **API מלא**: endpoints לכל פונקציונליות
✅ **ממשק משתמש**: ממשק וב נוח וידידותי

## מבנה הפרויקט

```
drug_agent/
├── src/
│   ├── app.py                 # אפליקציית Flask
│   ├── enhanced_scraper.py    # מודול חיפוש מתקדם
│   └── drug_scraper.py        # מודול חיפוש בסיסי
├── templates/
│   └── index.html             # ממשק משתמש
├── requirements.txt           # תלותים
├── run_server.py             # הפעלת השרת
├── ecosystem.config.js       # תצורת PM2
└── API_DOCUMENTATION.md      # תיעוד API מלא
```

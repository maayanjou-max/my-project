# סוכן מידע תרופות / Drug Information Agent

סוכן חכם לחיפוש מידע על תרופות מתוך מקורות מהימנים בלבד.

## תכונות

- חיפוש מידע על תרופות לפי שם גנרי או מסחרי
- תמיכה בעברית ואנגלית
- מקורות מידע מהימנים:
  - MicroMedex Solutions
  - UpToDate
  - MedlinePlus
- הודעת "לא נמצא מידע אמין" אם המידע לא נמצא במקורות הרשמיים

## התקנה

```bash
pip install -r requirements.txt
```

## הרצה

```bash
python src/app.py
```
